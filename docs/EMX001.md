# EMX001 — Historical Representation Census and Wide-Net Matrix Freeze

**Status:** Authorized development document.  **Result:** `MATRIX_V1_FROZEN`.

EMX001 creates a non-destructive matrix of historically used or independently
defensible native representations. A historical result remains valid only
under its frozen regime: historical validity is distinct from physical
interpretation. Negative results close exact cells, never a whole
representation.

Each candidate has the regime tuple `(R,S,G,O,tau,X,B,P,K)` for representation,
source regime, geometry, observer, temporal regime, source count, boundary,
preparation, and collective scale. Only physically compatible tuples are
listed. Full native state has physical-reference priority where historical
artifacts permit it.

Matrix v1 freezes canonical DEV167 native mechanics for active rows:
`sigma(epsilon)=(1-epsilon^2)/epsilon`, `F_ab=sigma(epsilon) rhat`.
Historical scalar mechanics are retained only as controls. No matrix execution,
new force, degree of freedom, fitted threshold, rotation, phase, amplitude,
frequency, direct N26/N27 force, Maxwell mapping, E/B label, ranking, or score
weights are authorized.

The next development is preselected, not executed: `EMX002_TEST_SELECTION =
COMMON_NATIVE_PRIMITIVE_BATTERY`, beginning T01–T05.
